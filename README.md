# Alla for Synthesia

A responsive, static personal landing page. No dependencies or build step.

Preview: `python3 -m http.server 4173`

GitHub Pages: select **GitHub Actions** under repository Settings → Pages. The included workflow publishes on pushes to `main`.

The supplied CV and employer logos live in `assets/`. Download CV links appear in the hero and closing section.

Search engines are instructed not to index the HTML page through a robots meta tag. Crawling is not blocked so crawlers can read the directive. This does not restrict access or apply to the public GitHub repository or CV PDF.
